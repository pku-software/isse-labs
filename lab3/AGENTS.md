# Lab 3 Agent 执行规则

当用户进行 Lab 3 时，先完整阅读同目录 `README.md`。它是给学生阅读的说明，也是交互式实验流程。课程 README 和本文件只读；用户明确要求维护课程文档时除外。

1. Codex 本地工作目录为学生个人 Fork 的 `isse-labs/` 根目录。学生个人文件只在当前分支 `lab3/<学号>-<姓名>` 对应的 `lab3/<学号>-<姓名>/` 中创建、修改和提交。先核对远端、分支和目录，不猜路径，不把工具输出或临时目录当成个人目录；不得修改 Lab 2 原目录。
2. 首次回复自然说明最终目标、GitHub → ACR 云端构建 → ECI 运行 → 浏览器验证的路线、学生与 Agent 的分工和下一件事。`[AGENT ACTION]` 等标记、阶段名仅供内部控制，不在正常对话中播报。说明下一项操作及预期结果后再行动，不反复无意义地问“是否继续”。
3. 一次只推进当前阶段。实际改代码前，先阅读学生 Lab 2 应用，解释继续使用后端环境变量 Key、无鉴权公网接口在开放期间的风险、将改哪些文件及具体计划；等待学生确认。不得自行改成前端输入 Key、额外加入鉴权系统，或把本地 Docker 安装变成必做。
4. 本 Lab 必做路径是 ACR 从学生**个人 GitHub Fork 的个人 Lab 3 分支**云端构建镜像，再由 ECI 运行。不得要求学生安装 Docker Desktop/WSL、本地 `docker build`、`docker run`、`docker login` 或 `docker push` 作为必做。学生自愿本地练习时才提供相应指导。ECI 不会直接运行 GitHub 源码；确认代码已 Push、构建上下文正确、ACR 镜像及标签真实存在后才能部署。
5. 学生亲自操作 GitHub、阿里云控制台、付费资源、真实 Key 和要求其执行的命令或浏览器验证。Agent 编写代码、配置、准确指引和排错说明，不替学生授权账号、创建/购买/释放云资源，也不替学生完成其应亲自观察的操作。
6. 学生说“已完成”只是触发核验。先尝试打开并读取 Codex 内置终端的本次命令与输出；若不可用，请学生打开当前任务终端后重试。云控制台和浏览器尽量使用当前可用的内置浏览器或确实可用的读取能力；若无法读取，请学生提供脱敏输出或截图。不能用 Agent 自己执行的命令冒充学生操作，不能凭口头回复认定成功。需核对这是本次操作而非旧结果。
7. 思考题先由学生回答，再评价、提示和追问。不要先给标准答案，不替学生编造其未表达的观点。
8. 不索取、读取、输出、保存或提交真实 DeepSeek Key、阿里云/ACR/GitHub 密码或令牌。Agent 不打开 `.env`，不打印环境变量值。Key 只由学生在 ECI **运行时环境变量**中手动设置，不进源码、GitHub、Dockerfile、构建上下文、ACR 构建参数、镜像、URL、前端请求、聊天记录、日志或对话。检查 Git 忽略与 Docker 忽略规则，但不读取密钥内容。
9. 本 Lab 用公网 HTTP 做短时演示。提醒学生聊天内容在浏览器到 ECI 的链路不加密；Key 留在后端，不随浏览器请求传输。但无鉴权的公网聊天 API 在开放时可能被他人调用并产生模型费用。只用实验专用 Key 和非敏感测试内容，缩短开放时间；结束后学生废除实验 Key，并释放本实验创建且不再使用的计费资源。短时运行、事后废除不是 HTTPS 或鉴权的替代品。
10. 容器内不用 Flask debug 开发服务器对公网服务。优先让 Gunicorn 单 worker 监听 `0.0.0.0:5001`，由同一个 Flask 容器提供页面、静态资源和 API。ECI 安全组只开放应用所需入口。本 Lab 不要求云端持久化；容器临时文件不可当作可靠长期数据。
11. 每个完成且经学生实际验证的阶段，有对应文件变化时创建有意义的 Commit，不制造空 Commit。实验过程中不生成或总结 `AGENT_TRACE.md`。最后由学生使用 Codex 的“复制为 Markdown”或可用分享功能留下真实轨迹；Agent 只检查敏感信息，不能以总结冒充记录。
12. 要求学生自行创建的文件，只给准确路径和所需内容，不指定 `nano` 等编辑器；前端交互不依赖 `alert()`、`prompt()`、`confirm()`。云控制台和价格可能变化，以实际界面为准。若 ACR 个人版不可用或 ECI 无法按课程范围部署，先说明原因并停下，不擅自购买企业版、ACK、ALB、NAT 或 ECS；目标不确定时不覆盖、删除或释放资源。
