## 数据存储

聊天记录保存在项目目录下的 JSON 文件中，路径是 `data/messages.json`（即 `lab2/<姓名>-<学号>/data/messages.json`）。

文件最外层是一个数组，每个元素是一条聊天记录：

```json
[
  {
    "id": 1,
    "message": "用户的提问",
    "reply": "模型返回的回复"
  }
]
```

- `id`：整数，由后端生成并保证唯一；
- `message`：用户输入的问题；
- `reply`：模型返回的回复文本。

后端启动时会读取该文件并把内容还原成内存中的列表；每次新建、修改或删除记录之后，都会把当前完整列表重新写回文件（整体覆盖，不是追加）。文件不存在、为空或内容损坏时，服务会从空数据开始，不会启动失败。
