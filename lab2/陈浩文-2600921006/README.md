## JSON 数据保存

聊天记录保存在项目根目录下的 `data/messages.json`，使用 UTF-8 编码。文件由应用在首次成功保存聊天记录时创建。

文件最外层为数组，每个对象代表一次问答，包含唯一整数 `id`、用户消息 `message` 和模型回复 `reply`。示例结构：

```json
[
  {
    "id": 1,
    "message": "示例问题",
    "reply": "示例回复"
  }
]
```

- Flask 启动时读取文件；文件不存在或为空时，从空记录开始。
- 新增、修改或删除记录后保存当前全部记录，保存成功后才更新内存并返回成功响应。
- 保存时先写入同目录的临时文件，再替换正式文件；写入失败时 API 返回 JSON 错误。
- 删除记录不会使其他记录重新编号；重启后的新 ID 从已保存记录中的最大 ID 加一开始。
- 修改只更新用户消息，保留原有模型回复；发送新消息才会调用模型。
