## 数据持久化

聊天记录保存在 `data/messages.json` 中。文件最外层是 JSON 数组，每条记录包含 `id`、`message` 和 `reply`。Flask 启动时从该文件加载记录；创建记录会追加对象，修改会更新对应对象，删除会移除对应对象。每次变更都会写回文件，因此重启服务后仍可恢复记录。
