## 数据存储

聊天记录同时保存在 Flask 进程的内存和一个 JSON 文件里：

```
data/messages.json
```

文件最外层是一个 JSON 数组，每个元素是一条聊天记录：

```json
[
  {
    "id": 1,
    "message": "用户输入的内容",
    "reply": "AI 回复的内容"
  }
]
```

- Flask 启动时读取该文件，把里面的记录加载回内存；文件不存在或内容不是合法 JSON 时，从空记录开始，不影响服务启动。
- 每次创建、修改或删除记录后，内存中的整个数组都会重新写回文件。
- 新记录的 `id` 取已有记录中的最大 `id` 加一，因此重启后新增的记录不会和文件里的记录冲突。
- 不使用数据库；JSON 文件直接放在项目目录中，可以随时打开查看。
