# AI 聊天 Web 应用

一个最小但完整的 AI 聊天 Web 应用。

前端使用 HTML + CSS + JavaScript，在浏览器中提供聊天记录区域、消息输入框以及每条记录的修改与删除入口。
后端使用 Python + Flask，通过 RESTful API 提供聊天记录的创建、查询、修改与删除，并在服务端调用大模型 API 生成回复。
API Key 只保存在后端，通过 `.env` 管理。
