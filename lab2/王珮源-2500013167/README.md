# AI 聊天 Web 应用

> 个人 Lab 2 项目：一个与 Coding Agent 协作构建的最小 AI 聊天 Web 应用。

## 项目简介

通过 Flask 后端调用 DeepSeek 大模型，提供简洁的网页聊天界面，支持对话记录的增删改查。

## 目录结构（计划）

- `app.py`：Flask 后端入口，监听 `5001` 端口
- `frontend/index.html`、`frontend/style.css`、`frontend/app.js`：前端页面与脚本
- `.env.example`：环境变量示例（仅含占位符）
- `.gitignore`：Git 忽略规则
- `requirements.txt`：Python 依赖列表
- `data/`（如启用选做）：聊天记录 JSON 持久化目录
